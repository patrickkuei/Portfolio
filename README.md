# Patrick Yang — Portfolio

Personal portfolio of Shen-Kuei Yang (Patrick), full-stack engineer based in Tokyo.

Built with [magic-portfolio](https://github.com/once-ui-system/magic-portfolio) (Once UI + Next.js).

**Live:** https://shenkueiyang-portfolio.vercel.app

## Stack

- Next.js 16, React 19, TypeScript
- Once UI design system
- Fonts: Space Grotesk, Exo 2, Space Mono
- Deployed on Vercel

## Dev

```bash
npm install
npm run dev
```

## Content

- `src/resources/content.tsx` — person, home, about, work, social
- `src/resources/once-ui.config.ts` — theme, fonts, routes
- `src/app/work/projects/*.mdx` — project case studies
- `public/images/` — avatar and project cover images
