## Overview

QuickEdit is an inline video editing feature that lets Vyond users make fast, targeted edits to their videos without navigating away from the main creation flow. The goal was to reduce friction for common editing tasks — trimming, replacing assets, adjusting text — that previously required opening the full editor.

## Key Contributions

- **Editor UX**: Designed and built the inline editing panel in React with a streamlined UI focused on the most frequent editing operations.
- **Rendering Pipeline**: Integrated with Vyond's SQS-based async rendering backend, displaying real-time job progress and handling success/failure states gracefully.
- **State Management**: Used Redux to keep the editing state in sync with the rest of the application without disrupting ongoing creation sessions.

## Technologies

- **Frontend**: React 18, TypeScript, Redux, SCSS
- **Backend**: Node.js, RESTful API
- **Cloud**: AWS (SQS, EC2, EKS, S3), Docker
