## Overview

Steam's built-in wish list has poor UX — no sorting, no filtering, no way to share or discuss games with friends. This platform fills that gap: a social feed where gamers log in with Steam OpenID, curate sortable and filterable game wish lists, and publish posts for others to like, comment, and share. Built solo and running in production with real organic traction — 50 weekly active visitors, 30% bounce rate, and 2:30 average session duration.

## Key Features

- **Steam OpenID Auth**: Seamless login via Steam's official OpenID — no separate account or password needed.
- **Social Feed**: Users publish wish lists as posts, with likes, comments, and sharing — building community around game discovery.
- **Smart Wish List**: Sort and filter across all saved games in one view, solving the core UX gap that Steam's native wish list ignores.
- **Steam Game Sync**: Automated pipeline syncs ~150,000+ Steam app records into PostgreSQL in under 30 seconds using batch upsert. Scheduled via cron job hitting a protected API endpoint.
- **Full Data Model**: PostgreSQL schema covering Users, SteamGames, Wishlists, WishlistItems, FeedPosts, Comments, CommentLikes, and WishlistLikes — all managed with Prisma ORM and hosted on Supabase.

## Technologies

- **Frontend**: Next.js, React, TypeScript
- **Backend**: Next.js API Routes, Prisma ORM, PostgreSQL (Supabase)
- **Auth**: Steam OpenID
- **Data Pipeline**: Steam Web API, batch upsert, cron-based sync
- **Infrastructure**: Vercel, Supabase, Docker, CI/CD
