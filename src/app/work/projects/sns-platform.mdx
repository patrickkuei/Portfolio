## Overview

A full-stack social networking platform built as a solo project, using AI-assisted development throughout — from architecture decisions to test generation. The platform is live and has grown to real organic users with strong engagement metrics.

## Key Contributions

- **Full-Stack Solo Build**: Designed and shipped the entire product solo — frontend, backend, database, and deployment — accelerated by AI-driven development workflows.
- **Real User Traction**: Grew to 50 weekly active visitors with a 30% bounce rate and 2:30 average session duration, indicating genuine engagement.
- **AI-Driven Development**: Used LLM-assisted coding, test generation, and architecture review throughout the build cycle as a force multiplier for solo delivery.

## Technologies

- **Frontend**: React, TypeScript
- **Backend**: Node.js, RESTful API
- **Infrastructure**: CI/CD, Docker
