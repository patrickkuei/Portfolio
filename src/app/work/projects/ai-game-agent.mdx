## Overview

Built in 2022 — before "AI agents" became mainstream — this project was an early exploration of autonomous LLM decision-making applied to game automation. The agent plays a game independently, making decisions (attack, rest, shop) by invoking tools through OpenAI's function calling API.

## Key Contributions

- **Agentic Decision Loop**: Designed a full action-selection loop where the LLM evaluates game state and picks the next action (attack/rest/shop) autonomously via function calling.
- **LangChain Integration**: Used LangChain to chain prompts, manage memory, and wire up tool calls — an early production adoption of the framework.
- **Infrastructure**: Ran the agent loop via cron job with a middleware layer handling game API interactions and response parsing.

## Technologies

- **AI**: LangChain, OpenAI API (function calling)
- **Backend**: Node.js, Cron
