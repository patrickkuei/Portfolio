## Overview

Text to Image brought AI-generated asset creation directly into Vyond's editor. Creators can type a prompt and receive custom images to use in their videos — no external tools, no context switching. I built the frontend integration for this feature working alongside the ML and backend teams.

## Key Contributions

- **Feature UI**: Built the text-to-image panel in React with prompt input, generation state, result grid, and one-click asset insertion into the editor canvas.
- **API Integration**: Integrated with the image generation API, handling async generation jobs, progress polling, and error states.
- **Asset Pipeline**: Wired generated images into the existing Vyond asset system (S3 storage, asset library) so they persist and are reusable across projects.

## Technologies

- **Frontend**: React 18, JavaScript, React Flux, Styled Components
- **Backend**: Node.js, RESTful API
- **Cloud**: AWS (SQS, EC2, S3), Docker
