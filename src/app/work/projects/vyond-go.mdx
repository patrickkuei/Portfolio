## Overview

VyondGo is Vyond's next-generation AI-powered video creation platform — a full rebuild designed to unlock a faster, more intuitive creative workflow for business users. I was part of the core frontend team that architected and shipped the product from scratch.

## Key Contributions

- **Frontend Architecture**: Built the core UI in React 18 with TypeScript and Redux, establishing scalable state management patterns used across the entire product.
- **AI Feature Integration**: Integrated AI-powered scene generation and asset suggestion capabilities directly into the editor, collaborating closely with the backend and ML teams.
- **AWS Pipeline Integration**: Connected the frontend with asynchronous rendering pipelines on AWS (SQS, EKS, S3), handling job status, progress feedback, and error recovery.
- **Performance**: Optimized component rendering and state updates to keep the editor responsive even with large, complex video projects.

## Technologies

- **Frontend**: React 18, TypeScript, Redux, SCSS
- **Backend**: Node.js, RESTful API
- **Cloud**: AWS (SQS, EC2, EKS, S3), Docker
