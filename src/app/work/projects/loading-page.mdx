## Overview

Video rendering takes time — and a blank or unhelpful loading screen is a frustrating dead-end for users. This project replaced Vyond's old loading state with a designed, informative experience that sets expectations, shows progress, and surfaces helpful tips while users wait.

## Key Contributions

- **Animated UI**: Built step-by-step animated instructions that show users what's happening during rendering, reducing perceived wait time and confusion.
- **Progress Integration**: Connected the UI to the rendering pipeline's real-time status, showing accurate progress indicators instead of indeterminate spinners.
- **Reduced Drop-off**: The redesign measurably reduced users abandoning the page mid-render by giving them confidence the process was working.

## Technologies

- **Frontend**: React 18, TypeScript, Redux, SCSS
